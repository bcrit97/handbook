# How to Ask for Help

Asking well is a core engineering skill. Before asking, spend 15-30 minutes on your own. Then post a comment on your issue with:

1. **Goal:** what you're trying to do
2. **Tried:** what you did, and what you expected
3. **Got:** the exact error or behavior (paste text, not a photo)
4. **Hunch:** what you think might be wrong

## Debug ladder (try in order)
1. Read the error message, top to bottom. The answer is often in it.
2. Run the failing test alone.
3. Add a `print()` to see actual values.
4. Search the exact error text.
5. Explain the problem out loud (rubber-duck it).
6. Ask.

Good questions earn respect, not penalties. No XP is ever lost for asking.
