# Glossary

Add terms as you meet them.

- **Repository (repo):** a project folder tracked by git
- **Branch:** a separate line of work
- **Commit:** a saved snapshot
- **Pull Request (PR):** a request to merge your branch, with review
- **CI:** automated checks that run on your PR
- **Test:** code that checks other code
- **Acceptance criteria:** the list of things that must be true for done
