# Definition of Done

An issue is done only when ALL of these are true:

- [ ] Work lives on its own branch and arrives via a Pull Request
- [ ] CI is green
- [ ] Provided tests pass and you did not edit them
- [ ] Every acceptance criterion in the issue is checked
- [ ] You completed the "Explain it back" with the product owner
- [ ] PR is reviewed and merged by the product owner

XP is awarded on merge, never before.

## Why this standard?
Real engineering teams don't accept "it works on my machine." Green CI plus a reviewer is the same bar you'd meet in a job.

## Rules of the road
- Copy-paste from the internet is allowed for *looking things up*. If you can't explain a line, it isn't yours yet.
- Using AI tools or search is fine for understanding. You must still be able to explain and modify what you submit.
- Stuck for 30+ minutes? See [How to Ask for Help](how-to-ask-for-help.md).
